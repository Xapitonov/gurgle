Gurgle (Гурчание)

Угадай эти слова

Нажимайте на буквы на клавиатуре, чтобы ввести предположение. Используйте Клавишу назад, чтобы стереть. Когда вы закончите предположение, нажмите Enter (ввод). Если вы угадали слово правильно, заиграет музыка, и появится короткое сообщение. Нажмите на слово, чтобы увидеть его определение.

Цвета отображения

Буквы, которые есть в слове, но стоят не на своем месте, станут желтыми. Если они на своем месте — станут зелеными. Если их нет в слове — они станут серыми. Продолжайте пытаться, пока не угадаете слово. Дисплей прокрутится вверх, если у вас закончатся попытки. Цвета можно изменить, выбрав Цвета выделения в меню.

Заблокировать буквы

Долгий нажим на букву в текущем предположении заблокирует её, что сделает её серой. Долгий нажим снова, чтобы снять блокировку. Заблокированные буквы будут пропущены при вводе и удалении букв. Долгие нажатия на буквы, не входящие в текущее предположение, откроют меню, как ниже.

Добавить акценты

Долгий нажим на букву в завершенном предположении. Это откроет всплывающее меню неакцентированных и акцентированных букв. Выберите нужную неакцентированную или акцентированную букву.

Поменять Enter (ввод) /Backspace (пробел),

Долгий нажим на клавишу Enter (ввод) или Backspace (пробел), чтобы поменять их местами.

Значение

Нажмите на любое слово, чтобы увидеть его значение. Добавьте любые необходимые акценты, как указано выше.

Обновить

Нажмите кнопку Обновить на панели инструментов, чтобы очистить дисплей и угадать другое слово. Слова выбираются случайным образом из списка и проверяются, чтобы убедиться, что они не использовались недавно.

Поделиться

Изображение

Поделитесь изображением текущего дисплея.

Текст

Поделитесь буквами и цветами завершенных предположений. Выберите приложение WordleSolver для выбора следующего предположения.

Код

Отобразите алфавитно-цифровой код и QR-код, который представляет новую последовательность слов для угадывания. Этот код можно поделиться с другой копией Gurgle (Гурчание) на другом телефоне, чтобы установить ту же последовательность слов. Нажатие кнопки QR-кода в диалоге поделится изображением QR-кода. Нажатие кнопки кода поделится алфавитно-цифровым кодом.

Темы

Выберите цветовую тему из кнопки Темы на панели инструментов.

Варианты

  •  Конфетти – Выберите отображение конфетти при угадывании слова.
  •  Звук триумфа – Выберите звук триумфа при угадывании слова.
  •  Слово по умолчанию – Выбор для включения слова по умолчанию. Первое введенное слово станет словом по умолчанию, введенным в начале каждой игры. Сбросить для очистки слова.

Словарь

Выберите словарь для поиска значения слова. Викисловарь (онлайн) встроен, Aard2 и Quickdic – это приложения, которые можно установить из F-Droid.

Язык

Выберите Язык из меню.

Получить код

Код

Введите код, переданный другой копией Gurgle (Гурчание), чтобы установить ту же последовательность слов. Если игра в процессе, нажмите кнопку обновления, чтобы начать новую последовательность. Вы можете также придумать свой код. Он не должен содержать два символа равенства в конце (=), но не сработает с одним.

QR-код

Открывает приложение камеры на телефоне для фотографирования QR-кода. Приложение попытается его декодировать. Есть много очень хороших приложений для сканирования QR-кодов и штрих-кодов, которые справляются лучше.

Получение кода

Если приложению отправлен код или изображение QR-кода, оно установит новую последовательность слов, если код был успешно декодирован. Это не влияет на текущую игру. Если игра находится в процессе, нажмите кнопку обновления чтобы начать новую последовательность.

Цвета выделения

Появится диалоговое окно с двумя предположениями, одно из которых содержит некоторые буквы из слова на неправильных местах и правильное предположение, а также три спектра. Измените цвет букв на неправильных местах, нажав на верхний спектр, а правильные буквы — с помощью среднего спектра. Измените оттенок серого букв, которых нет в слове, с помощью нижнего спектра. Кнопка Сбросить восстановит цвета по умолчанию, кнопка Отмена ничего не изменит, а кнопка ОК примет изменения.

Жульничество

Используйте моё Crossword (Кроссворд) или WordleSolver приложение для жульничества.
